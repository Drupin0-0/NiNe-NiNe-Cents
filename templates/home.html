Descrição do Projeto

Esta API permite realizar o controle completo e automatizado do estoque de produtos.

Endpoints do Usuário

POST /userprofile/register/

URL Completa: http://127.0.0.1:8000/userprofile/register/

Descrição: Realiza o cadastro de novos perfis de usuários no sistema de estoque.

Exemplo de requisição:

{
    "user": "joao.silva",
    "birthdate": "1990-05-15"
}
GET /userprofile/register/

URL Completa: http://127.0.0.1:8000/userprofile/register/

Descrição: Lista todos os perfis de usuários cadastrados no sistema de estoque.

Endpoints do Produto

POST /product/register/

URL Completa: http://127.0.0.1:8000/product/register/

Descrição: Realiza o cadastro de novos produtos no sistema de estoque.

Exemplo de requisição:

{
    "user": "joao.silva",
    "birthdate": "1990-05-15"
}
GET /product/register/

URL Completa: http://127.0.0.1:8000/product/register/

Descrição: Lista as informações de todos os produtos registrados.
